# ASSETS TODO

Every asset in the mod is an **original placeholder** generated by `tools/AssetGen.java` (`java tools/AssetGen.java`).
No Toei/Shueisha/Dragon Block C art is bundled. To swap in final art, replace the file at the same path (same size/format) — no code changes needed.

Reference material (for drawing originals, or for adding art yourself for **private use only**): the Dragon Block V wiki (https://dragonblockv.wiki.gg/), the Dragon Block C CurseForge page and JinGames wiki, and Dragon Ball fan wikis.
